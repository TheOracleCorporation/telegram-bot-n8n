# Telegram Bot — n8n

Telegram-бот, разработанный с использованием n8n и внешних API.

## Возможности

- Обработка сообщений пользователей в Telegram
- Автоматизация обработки запросов
- Взаимодействие с внешними сервисами через API
- Настройка последовательности действий с помощью workflow в n8n

## Используемые технологии

- n8n
- Telegram Bot API
- REST API
- Webhooks
